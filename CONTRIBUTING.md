# Contributing to the Statly docs

This repository is documentation only — the Statly Chrome extension itself is closed source. Contributions here help keep the docs accurate and useful for users and researchers.

## Ways to help

- **Fix errors** — typos, outdated pricing, broken links.
- **Add screenshots** — drop annotated PNGs/GIFs into `docs/screenshots/` (see that folder's README for naming conventions).
- **Improve the FAQ** — if you asked support a question that isn't covered in [FAQ.md](FAQ.md), add it (with the answer) via PR.
- **Suggest roadmap items** — open an issue using the "Feature request" template.
- **Report doc bugs** — open an issue using the "Documentation issue" template.

## Making a change

1. Fork this repository.
2. Create a branch: `git checkout -b docs/short-description`.
3. Make your edit. Keep Markdown formatting consistent with the rest of the repo.
4. Open a pull request describing what changed and why.

## Style guide

- Use sentence case for headings.
- Keep tables and bullet lists scannable — short phrases over long paragraphs.
- Link to [trystatly.com](https://trystatly.com) for anything price- or plan-related instead of hardcoding numbers in more than one place, so updates only need to happen once.
- Don't add unverified claims — if you're not sure something is accurate, flag it in the PR description instead of guessing.

## Code of conduct

Be respectful and constructive. This is a small documentation project — keep discussion focused on making the docs better.

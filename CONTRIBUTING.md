# Contributing to the Statly docs

This repository holds Statly's public documentation only. Statly's code is closed source. Corrections and additions that keep these pages accurate are welcome.

## Ways to help

- **Fix errors:** typos, out-of-date facts, broken links.
- **Improve the FAQ:** if you asked a question that [FAQ.md](FAQ.md) doesn't answer, suggest it with the answer.
- **Suggest features:** open an issue, or email [info@trystatly.com](mailto:info@trystatly.com).

## Making a change

1. Fork this repository.
2. Create a branch: `git checkout -b docs/short-description`.
3. Make your edit, keeping the formatting of the page you change.
4. Open a pull request that says what changed and why.

## Style

- Plain, friendly English. Short sentences. Sentence case for headings.
- Statly is written "Statly". Platforms are "Instagram Reels", "TikTok", "YouTube Shorts" and "X".
- Statly updates daily: never call it real-time.
- Don't add claims you can't check. If you're unsure, say so in the pull request.
- Prices live on [trystatly.com/pricing](https://trystatly.com/pricing); if they differ from these pages, the website is right.

## Code of conduct

Be respectful and constructive, and keep discussion on making the docs better.

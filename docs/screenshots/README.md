## Adding a screenshot here

- Lowercase, hyphenated file names (`watchlist-niche-table.png`).
- PNG for still images; link videos rather than committing them.
- Use public accounts only, and keep files under a few MB.
- Write alt text that says what the image shows, for example `![Statly Watchlist: one niche's accounts and outliers](docs/screenshots/watchlist-niche-table.png)`.

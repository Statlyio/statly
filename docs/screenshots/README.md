## Naming & format

- Use lowercase, hyphenated filenames (`audit-overview.png`, not `Audit Overview.PNG`).
- PNG for static screenshots; GIF or MP4 for short interactions (Statly's own site uses short MP4 clips for `audit.mp4`, `compare.mp4`, `merge.mp4`, `watchlist.mp4`, `trendfinder.mp4` — you can reuse the same clips here).
- Keep individual files under a few MB where possible; large videos are better linked than committed directly.
- Reference new images from [`README.md`](../../README.md) once added, e.g.:

  ```markdown
  ![Audit dashboard](docs/screenshots/audit-overview.png)
  ```
